10.3 Implementation mistakes — do not regress
pd.read_csv without keep_default_na=False turns sodium ("NA") into a missing value → resolves to gene XK.
Scoring an unresolved member of must_merge as a pass. Unresolved counts as failure.
Using a stratified subsample for any check on a distribution. Use the _rand draw.
A "median rank ≥ threshold" check on a label whose prevalence exceeds 50% — the ceiling is 1 − p/2, so the check scores base rate.
Selecting markers by one statistic and scaling by another (range vs IQR) → |z| in the hundreds.
Putting the per-cohort-pair normalisation inside the containment loop.
Writing Python containing f-strings through a bash heredoc — \\n expands into real newlines. Use Edit.
Cell-weighting a cohort-identity guard — one 930k-cell label (Sorin|Cancer) dominates it.
Placing an ablation on the fold that holds out the ONLY cohort carrying the thing being ablated. Both arms become the same computation, and the gate prints a delta of 0.0000 without raising. See D-45.
Reporting a mean difference over 5 folds with no paired test and no interval. Two of this project's headline numbers (D-38's correlation, Gate 6's check 4) looked like results and were sampling noise. See D-44.
Averaging a macro score over classes the model had no training example of. The metric then measures the label space's cohort coverage, not the model. Report the transferable-class column beside it. See D-48.
Deriving the training roster from `role == 'train'` on disk. Building a value table for a non-training cohort silently adds it: after Stage 9, `[c for c in s3.available() if SPECS[c]['role']=='train']` returns SIX cohorts, so any Gate 3 / Gate 6 re-run would train on 6 and not reproduce. Pin the roster as a literal. See H14.
Redirecting a long background run's stdout without `python -u`. Python fully buffers it, so a 2-hour job shows zero progress until it exits. Use `python -u`, and give any multi-hour stage a per-fold checkpoint cache so a crash does not cost the whole run.
Building a "does the panel measure a defining marker" check on marker FREQUENCY alone, or on marker SPECIFICITY alone. Stage 12 check 5 took three attempts. Frequency-ranked markers make every cluster pass, because PTPRC and CD14 sit in every panel. Specificity-ranked markers make almost every cluster fail, because a database's rarest associations are its least reliable — ranking CD8 T-cell markers by specificity alone returns ZNF540, listed once. Require support first (>= 10 rows), THEN rank by specificity, and sanity-check the tool against cell types that are not in doubt BEFORE reading any result off it. See D-59.
Comparing macro-F1 across two label spaces with different class counts. Gate 7 check 4 measured a 3-cluster granularity difference moving the score by 0.09 at ARI 0.9828. Match the class count first — that is why s11 has a `matched` arm. See D-58.
